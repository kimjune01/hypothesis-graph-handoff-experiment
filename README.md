# Hypothesis graph handoff experiment

A copyleft, replayable pilot comparing Restart, Transcript, Structured handoff, and Hypothesis graph on a bounded mathematical continuation task.

The outcome is deliberately narrow: all four conditions solved the task, while the graph reached the first novel trial and finished fastest in this one run. See `results.md` and `result-hypothesis-graph.md`.
