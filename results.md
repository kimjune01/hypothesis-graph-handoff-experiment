# Pilot 4 results

Date: 2026-08-24

## Outcome

All four conditions returned the same verifier-accepted counterexample:

```text
(1, 4, 5, 6, 7, 11, 13, 16)
```

The hidden verifier recomputed `ML(v)=2/17` exactly and found no one- or two-element seed certificate. It did not match against the stored answer.

Time to first novel trial is measured from the first recorded tool event to the first `n=8` evaluation command. Structured first replayed Agent A's eight-test suite; that was classified as replay, not duplication. No condition reran Agent A's exhaustive `n<=7` audit.

False-claim inheritance is `undefined`: Agent A's frozen trajectory contained mistaken test expectations, but it killed and corrected them before handoff. Restart independently reported an incorrect exact value `ML(v)=19/176`; the hidden verifier found `2/17`. This was a self-generated final-explanation error, not an inherited claim, and did not change task acceptance.

## Claim ledger

- **Completion:** no separation. Every condition completed, including Restart.
- **Resumption cost:** graph reached the first novel trial 7.828 seconds before Transcript and 45.146 seconds before Structured in this single case.
- **Total wall time:** graph was fastest, 38.288 seconds faster than Transcript and 65.117 seconds faster than Structured.
- **Dollar cost:** graph was cheaper than Structured but $0.00586 more expensive than Transcript. It does not support an absolute cost claim.
- **Duplication:** no separation; all conditions recorded zero duplicates.
- **False-claim inheritance:** not measured because the natural premise was absent.

Under the Pilot 4 rule, this is a narrow case-level usefulness result for resumption time relative to Transcript and Structured handoff. It is also a ceiling-effect warning: identical working files made the task solvable from Restart, so the result does not show that a graph enabled success.

## Instrumentation result

Pilots 1–3 stopped before Agent B because artifact provenance failed increasingly strict checks:

1. block-level citations did not satisfy sentence-level provenance;
2. table-free prose still bundled multiple claims under one citation; and
3. schema-valid atomic citations still included claims not supported by their cited events.

This supports a separate engineering conclusion: syntactic provenance is not semantic support. It does not support a claim that graph representation itself is truthful.

## Limitations

- One task and one run per condition; no uncertainty estimate is meaningful.
- Artifact selection for Pilot 4 occurred after inspecting artifact form, though before any outcome run.
- All arms inherited Agent A's executable working tree, which made Restart unusually strong.
- The task was derived from a public case study. The no-tools recall probe returned `NO RECALL`, but contamination cannot be ruled out completely.
- The handoff artifacts were generated by the same model used for Agent B.
